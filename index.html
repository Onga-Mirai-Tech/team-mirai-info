このサイトについて（非公式ファンサイトです）

「チームみらい ウォッチ」は、チームみらいの活動を追いかけたい個人が運営する非公式のファンサイトです。政党「チームみらい」、所属議員、関係団体が運営・監修・承認しているものではありません。

掲載している記事・動画の内容についてのお問い合わせを、党や議員事務所へ送らないようお願いします。正確な情報は必ずチームみらい公式サイトや各報道機関の元記事でご確認ください。

情報の集め方

  • 党の公式発信：公式サイトのニュース一覧、公式 note（メイン・国会記録）、公式 YouTube
  • 議員の発信：所属議員の note・YouTube（X は自動取得できないため対象外です）
  • 大手メディア報道：Google ニュース経由で、 の記事だけを掲載しています

GitHub Actions で1時間ごとに自動更新しています。議員名での振り分けは見出し・説明文の文字から自動で行っているため、漏れや誤りが出ることがあります。

掲載しているのは見出しとリンクのみです。記事・動画の著作権は各配信元に帰属します。

「見たよ」ボタンについて

読んだ記事の目印として使えます。記録はお使いの端末のブラウザの中だけに保存され、運営者を含め外部には一切送信されません。そのため、別の端末やブラウザとは共有されず、ブラウザのデータを消去すると記録も消えます。
